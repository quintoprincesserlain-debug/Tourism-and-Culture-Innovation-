# Prompt Log: Tourism and Culture Innovation

## Task 2 — Zero-shot prompt
**Prompt used:** Create a simple, informative webpage explaining tourism and culture as innovation sectors. Include the importance of the sectors, opportunities for innovation, one project idea, and success measures. Use clear headings and accessible language.

**Result summary:** A single-page overview introducing digital heritage, community-based tourism, sustainable travel, inclusion, and the CultureConnect concept.

## Task 3 — Structured prompt
**Prompt used:** Build a webpage for a proposed tourism-and-culture innovation called CultureConnect. Organize it into: challenge, innovation, target users, expected impact, and implementation steps. Return separate `index.html`, `style.css`, and `script.js` files. Use responsive design and semantic HTML.

**Result summary:** A structured landing page with clearly separated sections and responsive cards.

## Task 4A — Few-shot prompt
**Prompt used:** Create a warm, community-centered tourism and culture webpage named Lakbay Kultura. Follow this content pattern: (1) short memorable headline, (2) plain-language concept description, (3) three experience categories with brief descriptions, and (4) a responsible-travel pledge with a working button. Use separate HTML, CSS, and JavaScript files.

**Result summary:** A visual concept page with heritage walks, food and traditions, arts and crafts, and an interactive pledge.

## Task 4B — Role prompt
**Prompt used:** Act as a tourism innovation and cultural-heritage adviser. Critically review a digital platform that promotes community-led cultural experiences. Assess strengths, risks, and recommendations, prioritizing local benefit, cultural consent, accessibility, sustainability, and privacy.

**Result summary:** A role-based review with strengths, gaps, safeguards, and a conditional recommendation to pilot the idea.

## Task 5 — Analysis prompt
**Prompt used:** Analyze the tourism-and-culture innovation concept. Identify the problem, root causes, proposed response, intended users, outcomes, risks, safeguards, and measurable indicators. Present the diagnosis in a clear Markdown report and create a final prototype webpage with separate CSS and JavaScript.

**Result summary:** A diagnosis report and final prototype for CultureConnect.

## Reflection
The outputs become more actionable as the prompts add structure, examples, and a specific expert role. The final analysis makes the problem, safeguards, and evaluation criteria explicit. All concepts remain proposals and should be validated with local communities before implementation.
